# 🧭 나의 운영실

프리랜서의 하루를 "생계 → 빚 → 비전" 순서로 붙잡아 주는 개인 대시보드입니다.
서버·로그인 없이 브라우저에서 바로 열리고, 기록은 그 브라우저(localStorage)에 저장됩니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| ☀️ 오늘 | 2시~5시에 할 한 가지, 이번 달 생존선, 🔁 매주 루틴(주 N회 체크, 월요일마다 새로 시작), 🔥생계 일부터 정리하는 할 일 목록 (📦 기타 칸, 1년 목표·작은 목표와 연결 가능) |
| 💸 돈 | 빚 500만원 → 0 챌린지(10칸 게이지, 목표일까지 매달 상환액 자동 계산), 수입 기록(수입원별), 고정비 |
| 🔭 비전 | 10년 → 5년 → 3년 → 1년 (기간마다 작은 산, 산마다 작은 목표와 정상까지 가는 산길, ▲▼ 순서 바꾸기) → 1년 목표 → 이번 분기 → 이번 달 → 이번 주 핵심 3개 |
| 📝 주간 리뷰 | 이번 주 숫자 자동 집계 + 5분 회고. 다음 주 핵심 3개는 비전 탭으로 자동 이동 |
| ⚙️ 설정 | 사용법, 빚 시작 금액, 백업 내보내기/가져오기, 초기화 |

## 사용 리듬

1. **처음 한 번**: 고정비 · 빚 목표 날짜 · 1년 목표 적기
2. **매일 아침**: 2~5시 한 가지 정하고, 🔥 생계 일부터 적기
3. **돈이 오가면**: 💰 / ✅ 버튼으로 기록
4. **일요일**: 주간 리뷰 5분
5. **한 달에 한 번**: 비전 다시 읽고 이번 달 목표 적기

## 실행 · 배포

- 로컬: `index.html`을 브라우저로 열면 끝.
- GitHub Pages: 저장소 Settings → Pages → Branch를 선택하고 `/ (root)`로 저장하면 폰에서도 열 수 있어요.

> 기록은 기기·브라우저별로 따로 저장됩니다. 기기를 옮기거나 브라우저 데이터를 지우기 전에 **설정 → 내보내기**로 백업하세요.
