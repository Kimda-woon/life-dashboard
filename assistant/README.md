# 🤖 비서 (아침·저녁 알림)

운영실 앱이 비공개 기록 저장소(`data/state.json`)에 올린 일정·할 일을 읽어서, 슬랙으로 보낼 글을 만드는 프로그램이에요.
개인 기록은 이 저장소(공개)에 없고, 이 프로그램은 글 모양만 정해요.

```
python3 -I assistant/briefing.py <state.json 경로> morning   # 아침 브리핑
python3 -I assistant/briefing.py <state.json 경로> evening   # 저녁 마감
TODAY=2026-11-02 python3 -I assistant/briefing.py … morning  # 날짜를 바꿔 시험
```

- 한국 시간(KST) 기준으로 날짜를 계산해요.
- 읽기만 해요. 파일을 고치지 않고, 아무 곳에도 보내지 않아요. (보내는 건 예약 작업이 해요.)
- 아침: 오늘 일정, 오늘 할 일(그날로 넣은 일 + 마감이 오늘인 일), 지난 날 못 한 일, 곧 마감(5일), 다가오는 일정(3일), 오늘의 규칙, 이번 달·주 목표, 진행 중 실험
- 저녁: 오늘 끝낸 일, 못 끝낸 오늘 일, 규칙 지킨 수, 내일 일정·마감
- 마지막 줄에 앱 기록 시각을 적고, 30시간이 넘으면 앱을 열어 달라고 알려요.
