# 🚇 쉬운 지하철

지하철이 어려운 어르신을 위한 길 안내 앱. 출발·도착역을 넣으면
"어느 호선을 타고, 어느 쪽 열차를 타고, 어디서 내려 어디로 갈아타는지"를 한 단계씩 알려줍니다.

- 타는 방향을 **다음 역 이름**으로 알려줌 ("탄 뒤 첫 역이 상왕십리역이면 맞게 탄 거예요")
- 내리기 바로 전 역, 지나가는 역 전체, 환승 안내
- 조금 더 걸려도 **갈아타는 횟수가 적은 길**을 먼저 안내
- 큰 글씨(3단계 조절), 큰 버튼, 최근 길 저장, 초성 검색(ㅇㅅㄹ)
- **폰 홈 화면에 설치** 가능, 설치 후엔 인터넷이 없어도 열림 (PWA)
- 지원 노선: 1~9호선, 경의중앙선, 수인분당선, 신분당선

## 폰에 설치하기
GitHub Pages 등 **https 주소**로 올려야 설치 버튼이 나옵니다 (`index.html`을 파일로 직접 열면 설치 불가).
- 안드로이드(크롬): 화면 아래 "홈 화면에 추가" 버튼 → 설치
- 아이폰(사파리): 공유 버튼(⬆︎) → "홈 화면에 추가"
- 앱 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 폰에 새 버전이 반영됩니다.

## 파일
| 파일 | 역할 |
|---|---|
| `data.js` | 노선별 역 순서 (지선은 path 별도, 순환선은 `ring: true`) |
| `router.js` | 길찾기(정거장 2분, 환승 가중치 12) + 방향 이름 만들기 |
| `app.js`, `style.css`, `index.html` | 화면 |
| `manifest.json`, `sw.js`, `icons/` | 홈 화면 설치·오프라인 |
| `router.test.js` | `node subway/router.test.js` — 길찾기 검증 |
| `verify.js` | `node subway/verify.js <역목록.csv>` — 외부 역 목록과 이름·순서 대조 |

## 데이터 대조 기록 (2026-10-07)
[kyckang/SeoulTransitMap_data](https://github.com/kyckang/SeoulTransitMap_data)의 `v1/seoul_subway_stations.csv`(공공 교통 데이터를 정리한 목록, 2026-10-05 생성)와 `verify.js`로 대조했습니다.
- 12개 노선 모두 역 이름·개수 일치. 대조로 고친 것: 4호선 진접 연장(진접·오남·별내별가람·불암산), 8호선 별내 연장(별내~암사역사공원), 1호선 연천·전곡·청산·탕정, 뚝섬유원지→자양, 화전→한국항공대, 지제→평택지제, 수인분당선 청량리, 1호선 가리봉 삭제
- 남은 차이: **4호선 당고개** — CSV에는 없지만 실제로 운영 중인 역이라 유지함
- 이름이 같은 다른 역은 **양평**(5호선 `양평(서울)` / 경의중앙 `양평(경기)`)뿐 (좌표로 확인)
- 순서: 불일치 15건은 모두 분기점·순환선 끝·역 코드 체계 차이로 확인(순서 오류 없음)
- ⚠ 서울시·data.go.kr 원본은 이 개발 환경에서 접속이 막혀 직접 대조하지 못했습니다. 서비스 전에 공식 자료로 한 번 더 확인하세요.

## 알려진 한계
- 소요 시간은 대략값(정거장 2분, 환승 5분). 급행·배차·실시간 정보는 반영하지 않음
- 열차 행선지 표시(“○○ 방면”)는 노선 끝역 기준이라, 중간에서 돌아가는 열차는 실제 표지판과 다를 수 있음 → 그래서 **다음 역 이름**을 가장 크게 안내
- 공항철도·GTX·경춘선 등은 아직 없음
