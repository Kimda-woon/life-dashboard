# 🚇 쉬운 지하철

지하철이 어려운 어르신을 위한 길 안내 앱. 출발·도착역을 넣으면
"어느 호선을 타고, 어느 쪽 열차를 타고, 어디서 내려 어디로 갈아타는지"를 한 단계씩 알려줍니다.

- 타는 방향을 **다음 역 이름**으로 알려줌 ("탄 뒤 첫 역이 상왕십리역이면 맞게 탄 거예요")
- 내리기 바로 전 역, 지나가는 역 전체, 환승 안내
- 큰 글씨(3단계 조절), 큰 버튼, 🔊 소리로 듣기, 최근 길 저장, 초성 검색(ㅇㅅㄹ)
- 서버·설치 없이 `subway/index.html`을 열면 동작. GitHub Pages로 배포하면 폰에서도 열림.

## 파일
| 파일 | 역할 |
|---|---|
| `data.js` | 2~9호선 역 순서 (지선은 path 별도, 순환선은 `ring: true`) |
| `router.js` | 최단시간 길찾기(정거장 2분·환승 5분) + 방향 이름 만들기 |
| `app.js`, `style.css`, `index.html` | 화면 |
| `router.test.js` | `node subway/router.test.js` — 왕십리→돌곶이 등 검증 |
