# 🚇 쉬운 지하철

지하철이 어려운 어르신을 위한 길 안내 앱. 출발·도착역을 넣으면
"어느 호선을 타고, 어느 쪽 열차를 타고, 어디서 내려 어디로 갈아타는지"를 한 단계씩 알려줍니다.

- 타는 방향을 **다음 역 이름**으로 알려줌 ("탄 뒤 첫 역이 상왕십리역이면 맞게 탄 거예요")
- 내리기 바로 전 역, 지나가는 역 전체, 환승 안내
- 조금 더 걸려도 **갈아타는 횟수가 적은 길**을 먼저 안내
- 큰 글씨(3단계 조절), 큰 버튼, 최근 길 저장, 초성 검색(ㅇㅅㄹ)
- **폰 홈 화면에 설치** 가능, 설치 후엔 인터넷이 없어도 열림 (PWA)
- 지원 노선: 1~9호선, 경의중앙선, 수인분당선, 신분당선, 공항철도, GTX-A, 경춘선

## 폰에 설치하기
GitHub Pages 등 **https 주소**로 올려야 설치 버튼이 나옵니다 (`index.html`을 파일로 직접 열면 설치 불가).
- 안드로이드(크롬): 화면 아래 "홈 화면에 추가" 버튼 → 설치
- 아이폰(사파리): 공유 버튼(⬆︎) → "홈 화면에 추가"
- 앱 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 폰에 새 버전이 반영됩니다.

## 파일
| 파일 | 역할 |
|---|---|
| `data.js` | 노선별 역 순서 (지선은 path 별도, 순환선은 `ring: true`) |
| `router.js` | 길찾기(정거장 2분, 환승 가중치 12) + 방향 이름 만들기 |
| `app.js`, `style.css`, `index.html` | 화면 |
| `manifest.json`, `sw.js`, `icons/` | 홈 화면 설치·오프라인 |
| `router.test.js` | `node subway/router.test.js` — 길찾기 검증 |
| `verify.js` | `node subway/verify.js <역목록.csv>` — 외부 역 목록과 이름·순서 대조 |

## 데이터 대조 기록 (2026-10-07)
### 1) 외부 역 목록 CSV
[kyckang/SeoulTransitMap_data](https://github.com/kyckang/SeoulTransitMap_data)의 `v1/seoul_subway_stations.csv`(2026-10-05 생성)와 `verify.js`로 대조: 15개 노선 **역 이름 차이 0건**.
순서 불일치 13건은 모두 분기점·순환선 끝·역 코드 체계 차이로 확인(순서 오류 없음). 이름이 같은 다른 역은 **양평**(5호선 `양평(서울)` / 경의중앙 `양평(경기)`)뿐(좌표로 확인).

### 2) 서울교통공사 공식 노선도 (2026-02 변경노선도 PDF, 사용자 제공)
역 이름이 그림(외곽선)이라 기계로 읽을 수 없어 **눈으로 확인한 항목만** 대조했습니다 (전체 역을 하나씩 대조한 것은 아님).
- 4호선: 노원–상계–불암산–별내별가람–오남–진접. **당고개는 지도에 없어서 삭제** (CSV와도 일치)
- 1호선 소요산–청산–전곡–연천, 지행~신창 순서, 병점–서동탄 ✔
- 경춘선 광운대~춘천, 경의중앙선 임진강–운천–문산, 5호선 하남검단산·마천 ✔
- GTX-A: 운정중앙–킨텍스–대곡–연신내–서울역 / 수서–성남–구성–동탄. **서울역~수서는 선이 없음(미개통)** ✔
- 6호선 응암순환: 응암→역촌→불광→독바위→연신내→구산→응암, 지도에 한 방향 화살표 ✔
- 지도에는 셔틀 운행 여부(성수지선·광명·서동탄 등)가 나오지 않아 아래 가정은 **여전히 미확인**
- ⚠ PDF 안에 눈에 보이지 않는 문구 "8호선 암사역사공원 ~ 별내 미개통"(스티커 레이어)이 있음. 지도에는 별내까지 개통된 것으로 그려져 있고 CSV도 같아 개통으로 두었지만, **현재 개통 여부는 확인 필요**

## 열차 운행 방식에 대한 가정 (실제와 다르면 `data.js`를 고치세요)
- **셔틀 구간(`shuttle: true`)은 갈라지는 역에서 갈아탄다:** 2호선 성수~신설동·신도림~까치산, 1호선 금천구청~광명·병점~서동탄·소요산~연천, 경의중앙선 문산~임진강
- **6호선 응암순환**은 한 방향(응암→역촌→불광→독바위→연신내→구산→응암)으로만 돈다
- **GTX-A**는 운정중앙~서울역, 수서~동탄 두 구간으로 나뉨 (서울역~수서는 개통 전이라 연결하지 않음. 개통 시 `data.js`에서 합치면 됨)
- 5호선 하남·마천 갈래, 1호선 인천·신창 갈래, 경의중앙선 서울역 갈래는 직통열차가 다닌다고 봄
- ⚠ 위 가정은 공식 운행 자료로 확인하지 못했음

## 알려진 한계
- 소요 시간은 대략값(정거장 2분, 환승 5분). 급행·배차·실시간 정보는 반영하지 않음
- 열차 행선지 표시(“○○ 방면”)는 노선 끝역 기준이라, 중간에서 돌아가는 열차는 실제 표지판과 다를 수 있음 → 그래서 **다음 역 이름**을 가장 크게 안내
- GTX-A는 정거장당 5분으로 계산(실제는 구간마다 다름), 경춘선 ITX-청춘·급행 정차 구분 없음
- 인천지하철·의정부경전철·용인에버라인·김포골드라인 등은 아직 없음
